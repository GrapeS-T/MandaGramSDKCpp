# MandaGram SDK — C++

Нативный SDK для разработчиков плагинов MandaGram на C++. Содержит заголовки API и исходники примеров для Windows x64 и Linux x86_64.

- [Подключение SDK и сборка примеров](docs/building.md)
- [Ревизия исходников и контрольные суммы](sdk-source.json)
- [Справочник API](https://mandagram.com/kb/api-reference/)

SDK должен соответствовать сборке клиента. Плагины выполняются внутри процесса, без песочницы; совместимость с произвольной версией MandaGram не гарантируется.
